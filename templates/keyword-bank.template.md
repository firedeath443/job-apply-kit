## Tailoring rules
1. Only reorder bullets, drop bullets, or reword with phrasings from the table above.
2. Put the bullets that match the posting's main duties first in each job.
3. Mirror the posting's terms in the summary.
4. Never add a skill or duty from "Never claim", even if the posting requires it. Flag it instead.
5. Stay within the page limit (build.py enforces this).
